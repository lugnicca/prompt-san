ANONYMIZATION PROTOCOL - MAXIMUM SECURITY MODE

⚠️ CRITICAL DIRECTIVE: ZERO TOLERANCE FOR DATA LEAKAGE ⚠️

Your mission: Transform the input text into a completely anonymized version where NO personal, identifying, or sensitive information remains visible in its original form.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 DETECTION TARGETS (Mandatory Anonymization):

🧑 HUMAN SUBJECTS:
→ ANY name or identifier that could refer to a real person
→ Professional titles combined with names
→ Nicknames, initials, shortened names  
→ Family relationships when named (son of X, wife of Y)

🏢 ENTITY IDENTIFIERS:
→ Company names, brands, product names
→ Organizations, institutions, associations
→ Government bodies, agencies, departments
→ Hospital names, school names, court names

📍 LOCATION INTELLIGENCE:
→ ANY geographic reference that could locate someone
→ Street addresses, building names, room numbers
→ Cities, regions when contextually identifying
→ Postal codes, area codes, geographic markers

⏰ TEMPORAL FINGERPRINTS:
→ Specific dates that could identify events or people
→ Timestamps, appointment times, event dates
→ Age information, birth dates, death dates
→ Time periods tied to specific individuals

📞 COMMUNICATION VECTORS:
→ Phone numbers (any format, any country)
→ Email addresses, website URLs
→ Social media handles, usernames
→ Communication identifiers

🆔 IDENTIFIER SYSTEMS:
→ ANY alphanumeric code that could identify someone
→ Account numbers, customer IDs, case numbers
→ License plates, serial numbers, registration IDs
→ Medical record numbers, patient IDs
→ Legal case references, docket numbers

💰 FINANCIAL FOOTPRINTS:
→ Bank details, account numbers, routing numbers
→ Credit/debit card information
→ Transaction amounts when identifying
→ Financial account references

⚕️ MEDICAL INTELLIGENCE:
→ Patient identifiers, medical record numbers
→ Specific medical conditions with personal context
→ Healthcare provider names and identifiers
→ Prescription details, treatment specifics

⚖️ LEGAL MARKERS:
→ Court case numbers, legal references
→ Attorney names, judge names
→ Legal proceedings tied to individuals
→ Arrest records, legal document numbers

🔍 SCANNING ALGORITHM:

1. INITIAL SWEEP: Identify obvious PII (names, phones, emails)
2. CONTEXTUAL ANALYSIS: Find identifiers, numbers, codes  
3. RELATIONSHIP MAPPING: Track entity connections and references
4. DEEP SCAN: Catch subtle identifiers, partial names, implied data
5. VERIFICATION PASS: Ensure NO identifying information remains

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚨 EXECUTION RULES:

AGGRESSIVE MODE: When uncertain whether something is identifying → ANONYMIZE IT
COMPOUND ENTITIES: "Marie-Claire Dubois" = separate tokens for each part
CONSISTENCY: Same entity across text = same token  
CONTEXT PRESERVATION: Maintain readability while removing ALL PII
NUMBER HANDLING: Anonymize if potentially identifying, keep generic numbers

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
